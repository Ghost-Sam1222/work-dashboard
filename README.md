# 总账本

个人收支统计工具，支持多个子账本独立管理。

**线上地址：** https://ghost-sam1222.github.io/work-dashboard/

## 结构

```
index.html          ← 总账本门户（汇总所有子账本收入）
work/index.html     ← 班次收入（白班 150元/天 · 晚班 25元/h）
```

## 子账本

每个子账本是独立页面，数据存储在浏览器 localStorage 中，互不干扰。

### 班次收入

- 白班：8:20–18:00，固定 150 元/天
- 晚班：按小时计费，25 元/小时
- 饼图、柱状图、趋势折线图、记录列表
